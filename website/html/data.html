In one paragraph

We use the mini part of the Music Streaming Sessions Dataset (Spotify, WSDM Cup 2019). It has two tables. The session log has one row per song played (about 168,000 rows in 10,000 sessions). The track table has one row per song with numeric audio features (about 50,000 songs). The log tells us what the listener did. The track table tells us what each song is like in numbers. The sections below show the source, size, key variables and quality checks, with plots.
